# FDX Academy — Kubernetes Troubleshooting Challenge

## Objective
Diagnose and fix a broken Kubernetes deployment.

## Difficulty
Intermediate

## Estimated time
60–120 minutes

## Tasks
1. Identify the root cause of the failure.
2. Fix the Kubernetes resources.
3. Verify that the application becomes healthy.
4. Explain the root cause and your changes.
5. Document the commands and test results.

## Acceptance criteria
- Workloads become healthy.
- The application passes the defined validation checks.
- Kubernetes configuration follows reasonable security practices.
- A clear explanation and test evidence are provided.

## Submission
Follow SUBMISSION.md and submit your repository URL
and commit reference through the FDX Academy challenge platform.

## Important
Never commit passwords, tokens, kubeconfig files,
cloud credentials, or other secrets.
